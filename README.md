# Trainingsplan Verbellen

Web-App zum Erfassen des Trainingsfortschritts beim Verbellen (Box & Mensch), inkl. Mehrhunde-Verwaltung, Export als Excel/PDF/JSON.

Der Trainingsfortschritt wird ausschließlich lokal im Browser des jeweiligen Geräts gespeichert (localStorage) – es gibt keinen Server, keine Datenbank, keine Übertragung von Trainingsdaten ins Internet.

Enthält außerdem den gleichen Trainingsplan als Excel-Datei (`Trainingsplan_Verbellen_Tracker.xlsx`).
